# 兼容性说明

[返回项目首页](../README.md) · [已知问题](known-issues.md) · [安装与版本校验](releases/README.md)

## Windows 安装与更新

当前安装包面向 Windows x64，按当前用户安装，包含 mpv 运行时。用户账号与设置保存在独立 AppData 中，与安装目录分离。缺少 WebView2 时，官方引导程序可能需要联网下载。

安装包未数字签名，Windows SmartScreen 可能提示警告。请从[官方 Releases](https://github.com/Lomiry/Miry/releases) 下载，并按[版本校验表](releases/README.md)核对文件。

更新需要手动下载安装。可在 About 中检查新版本并打开发布页面，当前没有后台自动下载安装。升级前请备份配置并保留用户数据，不要手动清除 AppData。

## 播放与显示环境

Miry 使用独立原生 mpv 播放，不主动修改 Windows 显示器刷新率，也不自动切换 Windows HDR。mpv 的 HDR 播放处理与系统 HDR 开关是不同功能。

真实远程 Emby、长时间播放，以及部分 HDR、Dolby Vision、AVR 和物理 DPI 环境仍需实机确认。媒体、服务器能力、输出设备和 Windows 环境不同，不能从单一环境的结果推断全部组合都受支持。

以下范围尚未取得完整的真实环境验证记录：

| 范围 | 仍需确认的内容 |

既有版本有作品搜索、电影弹幕样本、原生绘制与时钟同步的验证记录，v1.0.6 有官方只读签名验证记录。这些结果和在线弹幕正常的用户反馈，不代表上述全部场景均已完成验证。历史验证结论保留原适用版本和范围，详见[历史版本说明](releases/README.md)。

## 自定义 mpv 配置

自 v1.0.1 起，不支持脚本、include/profile、外部录制、网络及改变播放窗口归属的自定义 mpv 配置；旧配置可能需要移除不支持项。普通画质、音频、字幕、滤镜和 Shader 调节保留。

在线弹幕的数据覆盖、服务限流和使用边界见[使用说明](getting-started.md)。第三方许可和权利范围以[许可说明](../LICENSE-SCOPE.md)及其引用文档为准。
