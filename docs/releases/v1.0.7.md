# Miry v1.0.7

## 更新日志

- 双字幕位置支持实时预览、确认、取消及恢复默认。
- 副字幕字号可独立调节，范围 50%～200%。
- 弹幕透明度支持 0%～100%，精度 1%。
- 每次启动自动检查一次更新，播放期间延后提醒，自动检查失败静默处理。
- 新增应用内更新下载、真实进度显示、失败重试、数字签名及版本绑定验证。
- 新增 NSIS 应用内安装交接流程，优化 Windows 安装界面与安装完成行为，默认不勾选自动运行。
