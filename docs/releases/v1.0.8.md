# Miry v1.0.8

## 更新日志

- 全新优化 Windows 播放器界面，以及首页、影片详情和跨服务器搜索。
- 智能片源选择支持分辨率或码率优先，完善字幕、音轨与播放设置。
- 内置 DandanPlay 在线弹幕接入，保留 LogVar、自定义来源、手动匹配、优先级及失败回退。
- 优化 Mini 播放器、Emby 多服务器与多线路管理。
- 修复无限滚动异常，优化全屏连续播放及字幕/音轨切换。
- 改善播放、停止、切集的异步状态管理，以及超时缓存、多账号隔离、资源清理和可维护性。
