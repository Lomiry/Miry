# 使用说明

[返回项目首页](../README.md) · [兼容性说明](compatibility.md) · [已知问题](known-issues.md)

## 连接与播放

添加你有权访问的 Emby 服务器并登录账号，即可浏览首页和媒体库。Miry 支持多服务器管理与切换；有多条访问线路时，可使用 Smart Route 多线路管理。

选择作品后，可按需选择媒体版本。播放支持 Direct Play、Direct Stream、Transcode 和 HLS，具体方式取决于服务器和媒体。观看进度、收藏、待看清单与观看记录用于继续观看和整理作品。

## 浏览媒体库

首页和媒体库支持影视搜索、中文输入与清空恢复。媒体库提供七种排序字段及独立升序 / 降序切换，搜索排序效果取决于服务器支持。

每页默认显示 30 条，可选择 20、30、50、100，或自定义 10–200；偏好在重启后保留。可输入页码，按 Enter 或点击按钮跳转，并保留筛选与搜索上下文。返回历史页面时会恢复并保存当时的每页数量。

## 字幕与画面

在播放器中选择主字幕和次字幕，可同时显示两路字幕，并实时调节大小与位置。

画面模式包括自动适应（默认）、填充屏幕和拉伸铺满，可在播放过程中切换。自动适应保留完整画面和原始比例；填充屏幕可能裁切；拉伸铺满可能使画面变形。主界面支持浅色、深色与跟随系统主题，也可调整 UI 字号和折叠侧栏。

## 在线与本地弹幕

发布版内置弹弹play服务接入，无需用户导入服务配置。可以搜索作品，自动或手动匹配弹幕；也可加载本地 Bilibili XML / ASS 文件。

在线弹幕使用弹弹play官方开放 API，受作品数据覆盖及服务限流影响，不保证每部电影、每集电视剧都有可匹配的弹幕。请求受限时稍后再试，不影响视频播放。

Miry 只读取并展示在线弹幕，不提供弹幕发送、弹弹play用户登录、批量弹幕下载或社区功能；不使用网页抓取、Cookie 模拟或非公开接口。在线服务的适配情况见[兼容性说明](compatibility.md)。

## 隐私与媒体来源

在线匹配使用作品标题、年份、季集信息及服务支持的作品 ID。Miry 不向弹幕服务发送 Emby Token、服务器地址、用户账号、媒体服务器凭据或播放历史。

媒体来自你自行配置的 Emby 服务器。Miry 不托管或分发影视内容，也不提供影视资源或服务器账号；请使用自己有权访问的媒体服务和内容。

## 帮助与反馈

使用问题与功能建议可通过 [GitHub Issues](https://github.com/Lomiry/Miry/issues) 提交。反馈时请附上版本和复现步骤，并隐藏账号、Token、服务器地址等私人信息。
